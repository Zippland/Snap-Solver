# 使用指南

## 第一次启动

安装 Node.js 22+ 和 uv 后，在项目目录运行：

```sh
npm ci
npm run setup
npm start
```

第一次安装会下载运行环境，之后只需 `npm start`。Windows 可在 PowerShell 运行相同命令。如果没有 uv，需要先安装 Python 3.12。

## 配对手机

让手机和电脑连接同一局域网。看到桌面状态“可以连接手机”后，用手机相机扫描二维码。

无法扫描时，展开电脑上的“手动连接与网络设置”：在手机浏览器打开显示的地址，再输入六位连接码。多个网卡时可切换地址。公司或访客 Wi-Fi 可能隔离设备，可以改用个人热点；Windows 防火墙需要允许专用网络访问。

macOS 需要在系统设置的“隐私与安全性 → 屏幕与系统音频录制”中允许开发态的 Electron，然后重启 App。手机使用时不需要屏幕录制权限。

## 添加模型

点击页面右上角的“连接模型”，选择一家服务，填写自己的 API Key；之后通过“模型设置”管理连接。型号和中转地址位于展开项里。保存只配置连接，不会发送模型请求；服务是否可用以实际账户权限为准。

已有密钥不会在简易设置表单回显。留空保存会保留原密钥；填写新密钥会替换。

## 截屏与提问

点击“截屏”直接添加整屏图片，重复点击就继续添加。需要裁剪时，点“框选”，拖动选区边角后点“添加选区到对话”。有多台显示器时，可在截图区上方切换，也可在框选页切换。“手机图片”用于添加手机里的图片；“模型设置”用于管理密钥，输入框底部的型号名称用于切换本次回答的模型。

图片按添加顺序编号，新对话中以大图或网格展示；已有回答或可用高度较小时收成横向缩略图，可左右滑动查看更多。点开图片可左右翻看、放大；支持单张删除和一键清空，10 秒内点“撤销”可恢复到队列末尾。每次最多 12 张。

图片都先留在输入框中，可以补充文字。点击发送后，图片与问题才会一起传给模型。题干、图表、选项分开显示时，可以分多次截屏并一次提问。

手机顶部会明确显示“电脑已连接”；断开、暂停或需要截屏权限时显示对应文字，点击状态可以查看处理提示。

回答支持公式、代码块与继续追问。模型菜单可以在同一对话中切换服务；新模型会接收当前对话的上下文。

## 运行与数据

关闭电脑窗口后仍在菜单栏 / 托盘运行，从托盘可以重新打开或退出。退出后手机无法连接。

在电脑“已配对设备”里点“取消配对”，会立即撤销手机访问；“换一个码”不会撤销已配对手机。“暂停手机访问”只是暂时断开手机，不等于停止已开始的生成；需要停止时请使用聊天中的“停止回答”，或退出整个 App。

手机之间共享这台电脑的聊天与设置。请只配对自己的设备，并仅在可信局域网使用。截图与聊天记录保存在电脑，发送的问题会按所选服务传到云端模型。

旧版中转地址也会导入。如果该中转仅支持厂商原生协议，需要在“模型与服务地址”里改成兼容的新接口地址：OpenAI 使用 Responses，其余内置服务使用 Chat Completions 兼容接口。
